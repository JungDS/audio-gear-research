# Step 0 — Baseline

## Objective

현재 Creative Sound BlasterX H7 Tournament Edition + Sound BlasterX AE-5를 모든 후보의 비교 기준으로 고정한다.

## Inputs

- 현재 사용 장비 정보
- RULES.md
- 제조사 공식 자료 및 독립 측정/리뷰

## Exact Tasks

1. H7의 정확한 모델/리비전과 공식 사양을 확인한다.
2. AE-5의 출력 특성과 현재 연결 방식이 H7에 미치는 영향을 정리한다.
3. H7의 음색, 저역, 중역/보컬, 고역, 해상력, 분리도, 공간감, 이미징을 기준화한다.
4. 착용감, 무게, 패드, 밀폐형 특성, 장시간 사용 특성을 정리한다.
5. 음악·일반 게임·애니메이션·영화 용도별 장단점을 정리한다.
6. 향후 비교에 사용할 평가항목과 사용자 우선순위를 확정한다.

## Minimum Coverage

- 제조사 공식 자료 최소 1개
- 독립 측정 또는 전문 리뷰 가능한 경우 2개 이상
- 장기 사용자 경험 자료 가능한 경우 2개 이상
- 확인한 사실과 사용자 체감/취향을 분리

## Required Outputs

- [x] research/00_baseline/result.md
- [x] data/evidence.csv 갱신
- [x] 향후 evaluations.csv에 사용할 비교 기준 확정

## Completion Gate

- [x] H7 + AE-5 기준 환경이 명확히 정의되었다.
- [x] 비교 항목이 빠짐없이 고정되었다.
- [x] 강점/약점이 근거와 함께 기록되었다.
- [x] 사용자 우선순위가 현재 대화 기준으로 정리되었다.

## Prohibited Shortcuts

- 후보 제품을 추천하거나 순위를 매기지 않는다.
- H7 단품과 H7 + AE-5 조합을 혼동하지 않는다.
- 현재 사용자 체감을 외부 리뷰로 덮어쓰지 않는다.

## Handoff

사용자 검토 후 Step 0을 COMPLETED로 변경하고 `research/00_baseline/handoff.md`를 작성한다.

완료 후에만 Step 1 — Brand Map으로 진행한다.
