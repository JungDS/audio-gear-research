# Research Outputs

각 단계의 사람이 읽는 조사 결과와 단계 인계 정보를 저장한다.

예상 경로:

- `00_baseline/result.md`
- `01_brand_map/result.md`
- `02_candidate_discovery/result.md`
- `03_product_status/result.md`
- `04_price_research/result.md`
- `05_pre_filter/result.md`
- `06_audio_analysis/result.md`
- `07_comfort_quality/result.md`
- `08_vs_current/result.md`
- `09_value_analysis/result.md`
- `10_finalists/result.md`
- `11_counter_review/result.md`

각 단계 완료 시 같은 폴더에 `handoff.md`를 작성한다.

예:
- `02_candidate_discovery/handoff.md`

해당 단계가 실제로 시작될 때 폴더와 파일을 만든다. 빈 디렉터리를 미리 만들지 않는다.
